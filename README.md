# Abelia Paysages — maquette

Maquette du site vitrine d'Abelia Paysages, paysagiste à Briis-sous-Forges (91).

Pages : `index.html` (accueil), `prestations.html`, `realisations.html`, `zone-intervention.html`, `contact.html`, `mentions-legales.html`.

Les pages sont générées par `outils/build.py` à partir de `outils/src/` (`python3 outils/build.py`). Feuille de style : `style.css`, script : `script.js`, images optimisées : `images/`.
